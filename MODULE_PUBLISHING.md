# Publishing Module

## Purpose

The publishing module owns social caption generation and platform publication orchestration for the final reel. It keeps Supabase staging, YouTube upload, Instagram upload, Facebook upload, success counting, and per-platform error capture behind a workflow-level interface.

## Public Interface

- `generatePublishingCaption({ topic })`
- `publishReel({ videoPath, topic, caption })`
- `cleanupPublishingStaging(publishResult)`

`publishReel` returns:

```js
{
  success,
  successCount,
  links,
  staging,
  errors
}
```

`links` preserves the existing shape used by Sheets and email:

```js
{
  yt,
  insta,
  fb
}
```

## Files Changed

- `src/services/publishingService.js`
- `src/main_automation.js`
- `MODULE_PUBLISHING.md`

## Legacy Cleanup

- Moved caption generation, Supabase staging, YouTube upload, Instagram upload, Facebook upload, and success counting out of `main_automation.js`.
- Captured per-platform upload errors in a structured `errors` array while preserving existing logging.
- Kept Supabase cleanup disabled in the same way as the existing workflow, but moved the cleanup decision behind `cleanupPublishingStaging`.

## Behavior Preserved

- Captions are still generated by `generateUnifiedSocialMediaCaption`.
- YouTube upload still runs independently from Supabase staging.
- Instagram and Facebook still upload through the Supabase public URL when staging succeeds.
- Meta uploads are skipped if Supabase staging fails.
- The workflow still treats one or more successful platform uploads as success.
- Sheets and email still receive `{ yt, insta, fb }` links.

## Dependencies

- YouTube OAuth environment variables.
- Instagram and Facebook environment variables.
- Supabase environment variables.
- Gemini/Groq keys used by caption generation.
- Network access to platform APIs.

## Risks

- Live publishing smoke tests were not run because they require external credentials, network access, and would create real/staged posts.
- Supabase cleanup remains intentionally disabled to preserve the current Meta upload behavior.
- `workflowController.js` still has its older upload flow and result formatting.

## Notes For Next Refactor

- A later publishing hardening pass should make Supabase cleanup explicit per platform readiness rather than permanently disabled.
